# WELL MUDDA S____

Pre-launch brand site for **Well Mudda S____**, a Bahamian toilet paper brand in product development.

## Positioning
- Bold consumer brand first
- Hospitality as an intended early distribution wedge
- Bahamas-born, designed to scale beyond The Bahamas
- No claims that the final tissue specification, manufacturer, certifications, or availability are confirmed

## Stack
- React
- Vite
- Pure CSS motion / mockups
- No backend dependency

## Local development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```

Output: `dist/`

Works on Cloudflare Pages with:
- Build command: `npm run build`
- Output directory: `dist`
